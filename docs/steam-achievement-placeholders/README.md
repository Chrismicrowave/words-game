# Steam achievement placeholder icons

Generated with the built-in image_gen tool. Six separate square PNGs; no game or Editor assets were changed.

- `*_achieved.png`: color icon → Steam Achieved.
- `*_unachieved.png`: grayscale icon → Steam Unachieved.
- `1`: COMPLETE_FIRST_WORD; `2`: COMPLETE_TWO_WORDS; `D`: COMPLETE_WORD_WITH_D.

The generated PNGs are larger than 256×256; Steam's achievement editor scales larger square icons to 256×256 on upload. These are temporary placeholders, not final artwork.
